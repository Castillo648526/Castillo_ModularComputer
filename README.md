# Castillo_ModularCalculator
REFLECTION


1) What functions did you create in your calculator program?
I created four functions: add_numbers(), subtract_numbers(), multiply_numbers(), and divide_numbers().
2) What parameters did your functions use?
Each function uses two parameters: num1 and num2.
3) What arguments were passed when the functions were called?
The two numbers entered by the user, num1 and num2, were passed as arguments to the functions.
4)How did your program use the returned value?
The returned value was stored in the result variable and then displayed to the user.
5) Why is it better to divide the calculator program into functions instead of writing everything in one long block of code?
Using functions makes the program easier to read, understand, test, and maintain. Each function has one specific task, so the code is more organized and can be reused when needed. When there are errors in code, you can find the line easily.
